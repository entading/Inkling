# Inkling

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

个人英语学习知识沉淀库：Markdown 文件即数据，检索快、可互联、界面简洁美观。

## 功能要点

- **四大板块**：词汇（IPA 音标）/ 短语 / 长难句 / 语法；词汇、短语支持 A–Z 字典序索引
- **检索**：全局搜索（模糊 + 精确优先）、命令面板 `Ctrl/Cmd + K`、板块内就地过滤
- **录入与编辑**：小表单生成词条骨架、分屏实时预览（Ctrl+S 保存）、`[[` 双向链接补全、暂停自动草稿
- **阅读**：衬线正文排版、标题目录、反向引用、上下篇导航；字体 / 字号 / 行距可自定义，支持导入字体文件
- **标签**：自配色标签注册表，支持重命名 / 深度删除；未注册标签一键批量注册
- **主题与发音**：浅色 / 深色 / 跟随系统；词条朗读与选中朗读（浏览器 TTS）
- **手机访问**：设置页一键开启局域网访问，手机扫码查看
- **桌面版**：安装即用、关闭窗口驻留托盘、应用内检查更新与一键升级
- **数据安全**：笔记就是本地 Markdown 文件；可开启 git 版本跟踪，误删可找回

## 安装桌面版（推荐）

从 [Releases](https://github.com/entading/Inkling/releases/latest) 下载 `Inkling-Setup-x.x.x.exe` 运行即可（Windows 10/11，免管理员权限）。安装包未做代码签名，SmartScreen 首次提示时点「更多信息 → 仍要运行」。

- **应用内更新**：设置 → 关于 → 检查更新，发现新版本后一键下载安装
- **首启引导**：首次使用会出现引导横幅，点「去设置」选择你的笔记文件夹；关闭后不再显示

## 网页版（可选）

需要 Node.js ≥ 20：

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173 （**必须用 localhost**，127.0.0.1 会被拒绝）。

## 你的数据

笔记是纯 Markdown 文件，默认在 `notes/` 下四个板块目录（`vocab/` `phrase/` `sentence/` `grammar/`）。一词条 = 一个 md 文件，文件名即词条名；运行期间往目录丢入新文件会自动收录，正文格式完全自由。

文件头部可选 frontmatter（全部字段可省略，显式写出的日期按所写值展示）：

```markdown
---
title: abandon          # 标题，缺省 = 文件名
ipa: /əˈbændən/         # 音标（词汇板渲染）
tags: [cet6, 高频]       # 标签
source: 真题 2024 Text 2 # 来源
created: 2026-09-01     # 缺省 = 文件创建时间
---

正文 Markdown……
```

- **数据目录可切换**：设置 → 数据目录，可指向任意文件夹（支持 Obsidian 等已有 Markdown 目录），重启应用生效，原目录文件原样保留
- **桌面版数据位置**：笔记在 `%APPDATA%\Inkling\notes\`；标签注册表、字体等全局数据在 `%APPDATA%\Inkling\`
- **误删兜底**：删除词条与标签批量操作可自动 git 提交留痕（设置 → 数据目录 → 启用版本跟踪）

### 从旧数据迁移

- **笔记**：整目录拷贝，再到「设置 → 数据目录」指定该文件夹即可
- **标签注册表**（颜色与注册日期不随笔记目录走）二选一：
  - 把旧环境的 `tags.json` 拷到新环境全局数据位置——保留注册日期
  - 或在新环境打开标签页，对未注册标签一键「批量注册」——颜色保留，注册日期重置为当天
